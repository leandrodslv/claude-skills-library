# Origine de ce skill

Ce skill fait partie du **Marketing Kit** de [ClaudeKit](https://claudekit.cc) (`ckm:design-system`).

Il n'existe pas de dépôt GitHub public pour ce skill : le Marketing Kit est un
produit payant de ClaudeKit, documenté sur https://docs.claudekit.cc/docs/marketing/skills/
mais dont le code source n'est pas open source. Impossible d'y vendre un
README officiel — ce fichier documente simplement la provenance.

**À quoi sert ce skill :** architecture de tokens de design (primitive →
sémantique → composant), variables CSS, échelles de spacing/typographie,
spécifications de composants et génération de slides respectant la charte.
