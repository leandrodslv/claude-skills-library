# Origine de ce skill

Ce skill fait partie du **Marketing Kit** de [ClaudeKit](https://claudekit.cc) (`ckm:design`).

Il n'existe pas de dépôt GitHub public pour ce skill : le Marketing Kit est un
produit payant de ClaudeKit, documenté sur https://docs.claudekit.cc/docs/marketing/skills/
mais dont le code source n'est pas open source. Impossible d'y vendre un
README officiel — ce fichier documente simplement la provenance.

**À quoi sert ce skill :** skill de design "parapluie" — identité de marque,
tokens de design, styling UI, génération de logos (55 styles, Gemini AI),
programme d'identité corporate (50 livrables, mockups CIP), présentations
HTML (Chart.js), design de bannières (22 styles), génération d'icônes
(15 styles, Gemini 3.1 Pro) et visuels sociaux (HTML → capture d'écran).
