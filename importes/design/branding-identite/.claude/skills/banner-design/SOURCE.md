# Origine de ce skill

Ce skill fait partie du **Marketing Kit** de [ClaudeKit](https://claudekit.cc) (`ckm:banner-design`).

Il n'existe pas de dépôt GitHub public pour ce skill : le Marketing Kit est un
produit payant de ClaudeKit, documenté sur https://docs.claudekit.cc/docs/marketing/skills/
mais dont le code source n'est pas open source. Impossible d'y vendre un
README officiel — ce fichier documente simplement la provenance.

**À quoi sert ce skill :** génération de bannières multi-formats (réseaux
sociaux, publicité, hero de site, print) avec plusieurs directions artistiques
et visuels générés par IA. Couvre Facebook, Twitter/X, LinkedIn, YouTube,
Instagram, Google Display, hero de site web et print.
