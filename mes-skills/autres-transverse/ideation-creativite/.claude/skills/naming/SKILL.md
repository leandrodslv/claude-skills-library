# Skill : Naming Créatif

## Ce que fait ce skill

Génère des noms de qualité studio pour les projets de Léandro, en s'appuyant sur sa sensibilité (solaire-mélancolique-rêveuse, design thinking, IA, UX), son univers lexical, et des méthodes de naming éprouvées.

---

## 1. Diagnostic d'intention

Avant de générer, pose une ou deux questions si le contexte est flou :
- Quelle est la **vibe / l'émotion** du projet ? (ex : doux, technique, mystérieux, estival)
- Quel est le **public cible** ? (utilisateurs UX, auditeurs, recruteurs, clients SaaS…)
- Y a-t-il des **mots à éviter** ou une **langue préférée** ?
- Est-ce que le nom doit être **brandable** (logotypable, court) ou **descriptif** (compréhensible au premier regard) ?

Si l'utilisateur a déjà donné ces infos dans sa demande, passe directement à la génération.

---

## 2. Profil de Léandro à garder en tête

Utilise ce contexte pour ancrer les propositions dans son univers :
- **Projets musicaux IA** : duo Velours Bleu (Anaïs Sète + Théo Montpellier), esthétique solaire-mélancolique-rêveuse, pop-rap français, nylon guitar, Rhodes, late-summer love, souvenirs flous
- **Projets tech/UX** : stack Figma, React, n8n, Claude API, accessibilité RGAA, alternance Paris
- **Style onomastique préféré** : noms évocateurs et poétiques > noms ultra-techniques ; bilingue ok ; courts et mémorables
- **Projets passés** : Alfred (majordome IA), Velours Bleu, Relay (agent), Hunter/Spark/Relay (triade agence)

---

## 3. Méthodes de naming utilisées

Pour chaque génération, s'appuyer sur **au minimum 3 méthodes** :

| Méthode | Description | Exemple |
|---|---|---|
| **Évocation sensorielle** | Nom qui déclenche une sensation (texture, lumière, son) | Velours, Brume, Écume |
| **Fusion lexicale** | Combinaison de deux mots/racines | Lunarize, Solcraft, Driftcode |
| **Métaphore d'usage** | Ce que le projet *fait* traduit en image | Relay, Anchor, Prism |
| **Initiales stylisées** | Acronyme qui sonne comme un vrai mot | NOVA, ARIA, OPAL |
| **Géographie poétique** | Lieu réel ou fictif évocateur | Montserrat, Sète, Riviera |
| **Verbe substantivé** | Action transformée en nom | Drift, Bloom, Haze |
| **Référence culturelle voilée** | Clin d'œil discret à une œuvre, un concept | Écho (mythologie), Wren (oiseau libre) |
| **Contraste doux/dur** | Opposition qui crée une tension mémorable | Ironpetal, Softcode, Duskforge |

---

## 4. Format de sortie standard

Toujours produire :

### 🎯 Shortlist (5–8 noms)

Pour chaque nom :
```
**[Nom]**
→ Méthode : [méthode utilisée]
→ Sens/vibe : [explication en 1-2 phrases]
→ Tagline possible : "[tagline courte]"
→ Domaine suggéré : [nom.fr / nom.io / nom.co / etc.]
```

### ⭐ Coup de cœur
Un nom recommandé avec justification plus longue (3-5 lignes) expliquant pourquoi il est particulièrement fort pour CE projet.

### 🔄 Variantes
Pour les 2-3 noms les plus forts, proposer 2 variantes orthographiques ou sonores (ex : Brume → Brüm, Bruma, Brumo).

---

## 5. Règles qualité

- **Jamais de noms génériques** : éviter Tech, Smart, Pro, Hub, App, Digital, Solutions
- **Tester la mémorabilité** : le nom doit fonctionner à l'oral (on peut l'épeler facilement)
- **Checker les connotations négatives** : éviter les doubles sens maladroits en FR/EN
- **Cohérence avec l'univers existant** : si le projet est dans l'écosystème Léandro (ex : agence, sous-marque musicale), le nom doit s'articuler avec les projets existants
- **Longueur idéale** : 1 à 3 syllabes pour du branding fort ; jusqu'à 4-5 pour des projets plus descriptifs

---

## 6. Cas spéciaux

### Artiste IA / Projet musical
- Intégrer des références géographiques du sud de la France si pertinent (Sète, Montpellier, Arles…)
- Favoriser les noms qui sonnent comme un nom d'artiste réel (humain plausible ou concept fort)
- Proposer un prénom + nom de famille fictif si c'est pour un persona artiste solo
- Vérifier que le nom évoque la bonne esthétique musicale (pas trop sombre pour du dreamy-pop)

### Agent IA / Workflow n8n
- Noms qui évoquent l'action, le relais, l'automatisation douce
- Références à la mythologie, aux métiers (Herald, Relay, Weaver, Scout)
- Courts, en anglais de préférence pour l'aspect technique

### Projet UX / Portfolio
- Noms qui reflètent la rigueur + la créativité
- Peuvent être en français pour le marché FR
- Éviter les noms trop "agence web 2010"

### Side project / App dev
- Noms brandables, domaine disponible probable
- Fonctionnent bien avec un `.io` ou `.app`

---

## 7. Si l'utilisateur veut affiner

Après la shortlist, proposer :
> "Tu veux qu'on creuse l'un de ces noms ? Je peux explorer des variantes, tester d'autres méthodes, ou générer un mood board lexical autour d'un mot-clé que tu aimes."

Si l'utilisateur donne un feedback du type "j'aime la vibe de X mais pas le son de Y", relancer avec une nouvelle batch en incorporant ce retour.
