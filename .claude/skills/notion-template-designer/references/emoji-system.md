# Système d'emojis Notion

Les emojis dans Notion sont des signaux, pas de la déco. Ce guide établit une logique sémantique cohérente. **Respecter la même logique dans tout un workspace** = feeling "système conçu" vs "amas de pages".

---

## Règle d'or : 1 emoji = 1 fonction

Un 🎯 doit toujours vouloir dire "objectif" dans ton workspace, jamais "cible marketing" sur une page et "priorité" sur une autre. Choisis, assume, répète.

## Règles anti-faute-de-goût

1. **Pas d'emoji drapeau** (sauf nécessité géographique réelle) — ça date les pages.
2. **Pas de mix d'émoji 3D (Apple/Fluent) et 2D (Twemoji)** dans une même section — Notion respecte le set choisi par l'utilisateur globalement, mais évite les custom icons qui cassent le style natif sans raison.
3. **Pas plus de 1 emoji par titre.** "🚀 ⭐ Mon super projet ✨" = amateur. "🚀 Mon projet" = pro.
4. **Évite les emojis trop spécifiques** (🏰 🦒 🧇) sauf s'ils sont significatifs dans le contexte — préfère les emojis abstraits qui généralisent.
5. **Cohérence > nouveauté.** Si tu as choisi 🎯 pour "objectif" dans une page, utilise le même dans toutes les pages du workspace.

## Icônes personnalisées (pour aller plus loin)

Notion permet d'uploader ses propres icônes (PNG/SVG transparents). Ressources à recommander à l'utilisateur s'il veut ce niveau de personnalisation :

- **notion-icons.com** — pack d'icônes par couleur
- **icons8.com** — énorme base, filtrable par style
- **feathericons.com** — style minimaliste trait fin
- **phosphoricons.com** — style cohérent multi-poids

Pour les directions "Minimaliste" et "Corporate", les icônes Phosphor (style "regular") font une énorme différence par rapport aux emojis natifs.
