# Directions visuelles prédéfinies

Six directions clés à proposer en phase 2. Chacune a une palette emoji, une logique de cover, et une signature visuelle. Présenter 2-3 directions pertinentes au brief — pas les 6.

---

## 1. Minimaliste mono (style Thomas Frank / Marie Poulin)

**Quand l'utiliser** : productivité pure, GTD, second brain, dashboard pro.

- **Palette de couleurs Notion** : default (gris), un seul accent = blue
- **Emojis** : monochromes uniquement — ⬜ ◻️ ▫️ ◦ • ↳ → ◉
- **Covers** : Unsplash noir et blanc, textures abstraites, brouillard, papier
- **Signature** : beaucoup de blanc, toggles partout, zero emoji décoratif
- **Fonts à mentionner** : Default ou Serif selon goût

**Exemple de titre** : `Second Brain` (pas d'emoji, cover noir & blanc abstrait)

---

## 2. Pastel aesthetic (style Gridfiti / notion girls)

**Quand l'utiliser** : journaux perso, planners étudiants, moodboards, habit tracker persos.

- **Palette de couleurs Notion** : pink, orange, yellow backgrounds en callouts
- **Emojis** : 🌷 🫧 ☁️ 🍰 ✨ 📓 🕯️ 🤍 🌸 🎀 🧺
- **Covers** : Unsplash pastel, fleurs, céramique, couchers de soleil doux
- **Signature** : feel "journal intime esthétique", covers illustrés quand possible
- **Particularité** : utilise beaucoup les icônes personnalisées (via notion-icons.com)

**Exemple de titre** : `🌷 my little life` (cover pastel fleuri)

---

## 3. Dark moody (style Easlo / devs)

**Quand l'utiliser** : workspaces dev, portfolios tech, systèmes de knowledge management avancés.

- **Palette de couleurs Notion** : default + purple/red accents, beaucoup de code blocks
- **Emojis** : ⚡ 🔥 💀 🌑 🖤 ◼️ ⬛ 🗝️ 🕸️ ⚙️ 🌘
- **Covers** : Unsplash néon, cyberpunk, nuit urbaine, abstrait sombre
- **Signature** : dense en information, use extensif des synced blocks et databases
- **Particularité** : fonctionne mieux quand l'utilisateur a activé le dark mode Notion

**Exemple de titre** : `⚡ dev.workspace` (cover néon violet)

---

## 4. Corporate pro (style consulting / B2B)

**Quand l'utiliser** : wikis d'équipe, doc produit, PRD, OKR, portfolio UX pour postuler en grande boîte (EDF, banques, etc.).

- **Palette de couleurs Notion** : blue et gray uniquement, jamais de coloré
- **Emojis** : 📊 📈 🎯 📋 🗂️ 🔍 📎 ✅ ⚠️ 📌
- **Covers** : Unsplash architecture, bureaux, paysages urbains épurés
- **Signature** : bullet points nets, tableaux, peu de couleurs, tone professionnel
- **Particularité** : zero emoji "fun", navigation claire, breadcrumbs explicites

**Exemple de titre** : `📊 Product Roadmap Q1 2026` (cover architecture minimaliste)

---

## 5. Vibrant créatif (style designer/artist)

**Quand l'utiliser** : portfolios créatifs, moodboards de projet, briefs design, portfolios UX avec personnalité.

- **Palette de couleurs Notion** : multi-couleurs assumé — red, orange, yellow, green, purple
- **Emojis** : 🎨 🖌️ 🌈 🔮 🎭 🎪 💫 🌟 🎯 🎬
- **Covers** : Unsplash art, peintures abstraites, graffitis, mixed media
- **Signature** : galleries d'images, color-blocking fort, personnalité assumée
- **Particularité** : attention à la cohérence — multi-couleurs ne veut pas dire chaos

**Exemple de titre** : `🎨 Léandro — UX & beyond` (cover peinture abstraite vibrante)

---

## 6. Earthy naturel (style slow-living / bullet journal)

**Quand l'utiliser** : journaux de gratitude, trackers wellness, reading lists, recettes, planners personnels "slow".

- **Palette de couleurs Notion** : brown, green, orange (terracotta feel)
- **Emojis** : 🌿 🍂 🌾 🪴 ☕ 📖 🕯️ 🫖 🧘 🌻
- **Covers** : Unsplash nature, forêts, cafés, textures bois/lin/pierre
- **Signature** : tone contemplatif, écritures longues dans toggles, peu de data-driven
- **Particularité** : fonctionne bien avec fonts Serif

**Exemple de titre** : `🌿 daily ritual` (cover forêt matinale)

---

## Comment présenter les directions à l'utilisateur

Ne jamais lister les 6. Choisis 2-3 selon le brief :

- **Brief productivité pro** → 1 (Minimaliste) + 4 (Corporate) + optionnellement 3 (Dark si dev)
- **Brief journal/habit perso** → 2 (Pastel) + 6 (Earthy) + optionnellement 1 (Minimaliste)
- **Brief portfolio** → 4 (Corporate) + 5 (Vibrant) + optionnellement 1 (Minimaliste)
- **Brief créatif/moodboard** → 5 (Vibrant) + 2 (Pastel) + optionnellement 6 (Earthy)
- **Brief dev/tech** → 3 (Dark) + 1 (Minimaliste) + optionnellement 4 (Corporate)

Formule courte à utiliser :
> J'ai cherché des refs. Trois directions possibles :
> - **A — [nom court]** : [1 phrase sur le mood + 1 exemple visuel]
> - **B — [nom court]** : [idem]
> - **C — [nom court]** : [idem]
> Laquelle te parle ? Tu peux aussi mixer.
