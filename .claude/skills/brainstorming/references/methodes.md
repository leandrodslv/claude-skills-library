## 1. HMW — How Might We {#hmw}

**Quand l'utiliser** : problème utilisateur identifié mais solutions floues, contexte UX/produit, challenge design.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  💡 HMW — How Might We               ║
║  Sujet : [reformulation du défi]     ║
╚══════════════════════════════════════╝

🔍 Reformulation du problème
──────────────────────────────
"Comment pourrions-nous [verbe d'action] pour [utilisateur cible]
afin de [bénéfice attendu], même si [contrainte] ?"

[ANGLE 1 — Amplifier le positif]
──────────────────────────────────
• HMW [idée 1]
• HMW [idée 2]
• HMW [idée 3]
...

[ANGLE 2 — Supprimer le négatif]
──────────────────────────────────
• HMW [idée]
...

[ANGLE 3 — Explorer l'opposé]
──────────────────────────────
• HMW [idée]
...

[ANGLE 4 — Changer la ressource]
──────────────────────────────────
• HMW [idée]
...

[ANGLE 5 — Analogie d'un autre secteur]
────────────────────────────────────────
• HMW [idée inspirée de X secteur]
...
```

**Conseil** : viser 3 HMW par angle minimum. Les HMW ne sont pas des solutions — ils restent des questions ouvertes.

## 2. SCAMPER {#scamper}

**Quand l'utiliser** : améliorer un produit, service, processus ou objet existant.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  🔧 SCAMPER                          ║
║  Sujet : [produit/service à améliorer]║
╚══════════════════════════════════════╝

S — Substituer (Substitute)
────────────────────────────
Quoi remplacer ? Qui d'autre ? Quels matériaux/processus alternatifs ?
• [Idée]
• [Idée]
...

C — Combiner (Combine)
───────────────────────
Quoi fusionner ? Quelle alliance inattendue ?
• [Idée]
• [Idée]
...

A — Adapter (Adapt)
────────────────────
Qu'est-ce qui existe ailleurs qu'on pourrait adapter ici ?
• [Idée inspirée de X]
...

M — Modifier / Magnifier / Minimiser (Modify)
──────────────────────────────────────────────
Changer la forme, la taille, la fréquence, le ton ?
• [Idée]
...

P — Proposer d'autres usages (Put to other uses)
──────────────────────────────────────────────────
Autres contextes ? Autres publics ? Autres moments ?
• [Idée]
...

E — Éliminer (Eliminate)
─────────────────────────
Qu'est-ce qu'on peut supprimer ? Simplifier radicalement ?
• [Idée]
...

R — Réorganiser / Inverser (Reverse/Rearrange)
───────────────────────────────────────────────
Inverser l'ordre ? Changer la perspective ? Faire l'opposé ?
• [Idée]
...
```

## 3. Crazy 8s {#crazy8s}

**Quand l'utiliser** : besoin de volume rapide, contrainte de temps, déblocage créatif.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  ⚡ CRAZY 8s                          ║
║  Sujet : [défi en une phrase]        ║
╚══════════════════════════════════════╝

Règle : 8 idées distinctes, 1 angle différent chacune.
Pas d'autocensure. Toutes les directions sont valides.

Idée 1 — [Angle radical]
─────────────────────────
[Description en 2-3 lignes]

Idée 2 — [Angle low-tech]
──────────────────────────
[Description]

Idée 3 — [Angle high-tech / IA]
────────────────────────────────
[Description]

Idée 4 — [Angle communautaire / social]
────────────────────────────────────────
[Description]

Idée 5 — [Angle gamification]
──────────────────────────────
[Description]

Idée 6 — [Angle analogie d'un autre secteur]
─────────────────────────────────────────────
[Description]

Idée 7 — [Angle minimaliste / suppression]
───────────────────────────────────────────
[Description]

Idée 8 — [Angle contra-intuitif / inversé]
───────────────────────────────────────────
[Description]
```

## 4. Reverse Brainstorming {#reverse}

**Quand l'utiliser** : blocage créatif, vouloir identifier les risques, challengeur d'idées reçues.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  🔄 REVERSE BRAINSTORMING            ║
║  Sujet : [objectif initial]          ║
╚══════════════════════════════════════╝

ÉTAPE 1 — Inverser le problème
────────────────────────────────
Objectif initial : "[Objectif]"
Problème inversé : "Comment GARANTIR l'échec de [objectif] ?"
ou : "Comment rendre [situation] encore pire ?"

[Idées pour aggraver / faire échouer]
──────────────────────────────────────
• [Comment échouer 1]
• [Comment échouer 2]
...

ÉTAPE 2 — Inverser les réponses en solutions
─────────────────────────────────────────────
• ↔ [Solution dérivée de l'idée 1]
• ↔ [Solution dérivée de l'idée 2]
...
```

## 5. Naming Canvas {#naming}

**Quand l'utiliser** : trouver un nom de produit, projet, feature, persona, marque.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  🏷️ NAMING CANVAS                    ║
║  Sujet : [ce qu'on nomme + contexte] ║
╚══════════════════════════════════════╝

🎯 Critères de bon nom
───────────────────────
• Cible : [pour qui]
• Valeur principale : [ce qu'il évoque]
• Ton souhaité : [ex. pro, fun, tech, humain...]
• Contraintes : [longueur, langue, .com dispo, etc.]

[CATÉGORIE 1 — Noms descriptifs]
──────────────────────────────────
Décrivent directement ce que c'est.
• [Nom] — Raison : ...
...

[CATÉGORIE 2 — Noms évocateurs]
─────────────────────────────────
Suggèrent une émotion, une image, une métaphore.
• [Nom] — Raison : ...
...

[CATÉGORIE 3 — Noms inventés / portmanteau]
─────────────────────────────────────────────
Mots fusionnés, néologismes, acronymes.
• [Nom] — Construction : [mot1 + mot2]
...

[CATÉGORIE 4 — Noms d'analogie / référence]
─────────────────────────────────────────────
Inspirés d'un univers (mythologie, nature, histoire...)
• [Nom] — Référence : ...
...

[CATÉGORIE 5 — Noms courts / punch]
─────────────────────────────────────
3-6 lettres max, faciles à mémoriser.
• [Nom]
...

🏆 Shortlist recommandée
─────────────────────────
1. [Nom] — Raison principale
2. [Nom] — Raison principale
3. [Nom] — Raison principale
```

## 6. SWOT Créatif {#swot}

**Quand l'utiliser** : analyse stratégique + génération d'opportunités, contexte business/produit.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  📊 SWOT CRÉATIF                     ║
║  Sujet : [entité / projet analysé]   ║
╚══════════════════════════════════════╝

Forces → Idées pour les amplifier
───────────────────────────────────
• Force : [X] → Idée : [comment l'exploiter davantage]
...

Faiblesses → Idées pour les transformer
─────────────────────────────────────────
• Faiblesse : [X] → Idée : [comment en faire un atout ou la supprimer]
...

Opportunités → Idées pour les saisir
──────────────────────────────────────
• Opportunité : [X] → Idée : [action concrète]
...

Menaces → Idées pour s'en protéger
─────────────────────────────────────
• Menace : [X] → Idée : [parade ou pivot]
...
```

## 7. Mind Map + Analogies {#mindmap}

**Quand l'utiliser** : exploration large d'un sujet, pas encore de direction définie.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  🗺️ MIND MAP + ANALOGIES             ║
║  Sujet central : [thème]             ║
╚══════════════════════════════════════╝

[BRANCHE 1 — Dimension X]
──────────────────────────
• Sous-idée 1.1
• Sous-idée 1.2
  └─ Sous-sous-idée 1.2.1

[BRANCHE 2 — Dimension Y]
...

[ANALOGIES — Et si c'était comme...]
──────────────────────────────────────
• Comme [domaine A] → Idée inspirée : [...]
• Comme [domaine B] → Idée inspirée : [...]
...
```

## 8. Jobs-to-be-done + Opportunités {#jtbd}

**Quand l'utiliser** : comprendre les besoins profonds d'un utilisateur + générer des features/services.

**Structure du canvas :**
```
╔══════════════════════════════════════╗
║  🎯 JOBS-TO-BE-DONE                  ║
║  Utilisateur : [profil cible]        ║
╚══════════════════════════════════════╝

Jobs fonctionnels (ce qu'ils veulent accomplir)
─────────────────────────────────────────────────
• Job : [tâche] → Opportunité : [idée de solution]
...

Jobs émotionnels (comment ils veulent se sentir)
──────────────────────────────────────────────────
• Job : [émotion] → Opportunité : [idée]
...

Jobs sociaux (comment ils veulent être perçus)
────────────────────────────────────────────────
• Job : [perception] → Opportunité : [idée]
...

Douleurs actuelles (pain points)
──────────────────────────────────
• Douleur : [X] → Antidouleur : [idée]
...

Gains attendus
───────────────
• Gain : [X] → Gain Creator : [idée]
...
```
