## 2. Registre des sources

| ID | Source (titre, auteur ou organisme) | Type | Publiée / données de | Méthode et échantillon | Fiabilité | Pertinence | Accès | Limites | Lien |
|---|---|---|---|---|---|---|---|---|---|
| S1 | … | statistique officielle | 2025 / 2024 | enquête, n = … | A | haute | complet | — | … |

Types possibles : académique · statistique officielle · institutionnel · sectoriel ·
référence UX · réseaux sociaux · données de demande · contenu d'acteur · norme ou
texte juridique · retour d'expérience · littérature grise · preprint ou archive ·
données internes · presse spécialisée.

Section distincte "Sources écartées" : ID · titre · raison (ex. D : chiffre sans
méthode, étude de vendeur).

## 3. Fiche d'extraction

```
[S#] — Titre court
Établit        : [DONNÉE] chiffre + année / [CONSTAT] conclusion de l'auteur
Méthode        : une ligne (type d'étude, échantillon, période)
Limites        : biais, périmètre, date
Sous-question  : SQ#
Citation       : « … » (≤ 15 mots, une seule) — optionnel
```

## 3 bis. Fiche corpus social

Une fiche par plateforme et communauté, pas par post.

```
Corpus         : [plateforme] · [communauté, hashtag ou page] · S#
Requêtes       : mots-clés utilisés
Période        : dates des contenus examinés
Examiné        : N fils / posts / commentaires (+ N non accessibles)
Niveau         : suffisant (≥ 30) / mince (10-29) / non exploitable (< 10)
Nb de requêtes : N distinctes (3 minimum)
Thèmes         : thème → présent dans X fils sur N (récurrence, pas un %)
Verbatims      : « … » (≤ 15 mots, anonymisé, sans pseudo ni lien) — optionnel
Désaccords     : positions contraires observées
Biais          : auto-sélection, sponsoring, bots, viralité, ancienneté
Non accessible : contenus bloqués ou derrière connexion
```

## 4. Matrice de triangulation

| Sous-question | S1 | S2 | S3 | S4 | Verdict |
|---|---|---|---|---|---|
| SQ1 | ✔ confirme | ✔ confirme | ✖ nuance | — | convergent, 1 réserve |
| SQ2 | — | — | — | — | **lacune** → livrable 7 |

Légende : ✔ confirme · ✖ contredit ou nuance · — non couvert. Les sources qui
reprennent la même étude sont regroupées sur une seule colonne.

## 5. Insight

```
Insight #N
Formulation   : sujet + verbe + contexte (descriptif, jamais prescriptif)
Preuves       : [S#, S#] DONNÉE / CONSTAT
Confiance     : fort / moyen / faible — justification en une ligne
Applicabilité : directe / à transposer / incertaine — pourquoi
HMW           : Comment pourrait-on…
```

## 6. Hypothèse à tester

```
H# : [énoncé testable, avec un critère qui la réfuterait]
Origine        : [S#] ou lacune
Méthode        : entretien / analytics / test d'usage / enquête
Profil visé    : …
```

## 7. Bibliographie APA 7 (travail d'études)

Format générique à remplir avec les métadonnées réellement relevées sur la source :

- Article : Auteur, I. (année). Titre de l'article. *Titre de la revue*, volume(numéro), pages. URL ou DOI
- Rapport : Organisme. (année). *Titre du rapport*. Éditeur. URL
- Page web : Auteur ou organisme. (année, jour mois). *Titre de la page*. Site. URL

Si un élément manque (auteur, date), l'écrire "s.d." ou omettre l'auteur selon la
norme, sans rien inventer. Ajouter la date de consultation pour les pages
susceptibles de changer.
