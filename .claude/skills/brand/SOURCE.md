# Origine de ce skill

Ce skill fait partie du **Marketing Kit** de [ClaudeKit](https://claudekit.cc) (`ckm:brand`).

Il n'existe pas de dépôt GitHub public pour ce skill : le Marketing Kit est un
produit payant de ClaudeKit, documenté sur https://docs.claudekit.cc/docs/marketing/skills/
mais dont le code source n'est pas open source. Impossible d'y vendre un
README officiel — ce fichier documente simplement la provenance.

**À quoi sert ce skill :** voix de marque, identité visuelle, frameworks de
messaging, gestion des assets et cohérence de marque. À activer pour du
contenu marqué, du ton de voix, des assets marketing ou un audit de
conformité à la charte.
